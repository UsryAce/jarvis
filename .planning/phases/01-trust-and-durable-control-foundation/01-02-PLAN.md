## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/local client -> REST/SSE/WebSocket/audio | Any local process or origin is untrusted until the backend session and scope checks pass. |
| runtime/control API -> `data/control.db` | Consequential transitions must be serialized, transactional, audited, and restart-safe. |
| mutable event input -> audit chain | Arbitrary payload/error text cannot enter durable audit truth. |
