<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/API -> credential service | Raw key input is untrusted, single-use, and must disappear after immediate protection. |
| Windows user/profile -> DPAPI ciphertext | Only the intended current user/profile may decrypt; backups do not create portable recovery. |
| opaque handle -> provider transport | Plaintext may exist only inside an authorized request lease and never in router/client caches. |
| security test -> output/knowledge sinks | Generated canaries are still secrets and cannot be printed or projected. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SC | Tampering | pywin32 dependency | mitigate | Tests are scaffolded without installation; implementation remains blocked on Plan 01-01. |
| T-01-08 | Information Disclosure | API/log/error/graph/vault/browser sinks | mitigate | Generated-canary scanner with sink-name-only failures and DPAPI-ciphertext-only persistence. |
| T-01-09 | Spoofing/Information Disclosure | wrong Windows SID/profile | mitigate | Same-user/DACL automation plus non-skippable cross-SID release checkpoint. |
| T-01-10 | Tampering/Elevation | stale or revoked provider client | mitigate | Generation/lease/crash matrix across text, speech, model and catalog caches. |
| T-01-11 | Denial of Service | failed replacement validation | mitigate | Preserve prior active key and generation; promote only after authoritative valid state. |
</threat_model>
