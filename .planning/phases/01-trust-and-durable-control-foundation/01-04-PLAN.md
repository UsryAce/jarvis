<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PyPI wheel -> privileged current-user process | Installed code can call DPAPI and change ACLs. |
| Python bytes -> Windows DPAPI | Plaintext crosses into the OS protection API and must not escape error/log paths. |
| filesystem ACL -> ciphertext/backup | Local users/processes must not gain ambient read/write access. |
| arbitrary payload -> durable/UI sink | Untrusted nested content may contain credentials or injection text. |
