## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator mutation -> durable control state | Stale/malicious clients cannot overwrite newer stop truth. |
| durable stop -> active runtime/effect boundary | In-memory cancellation is not proof of side-effect cessation. |
| supervisor/startup -> runtime recovery | Recovery must not start before trust and stop state are verified. |
