<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| one-time secret request -> DPAPI store | Plaintext must be protected before any persistence or response. |
| lifecycle command -> active provider generation | Stale or failed transitions must not displace a working key. |
| credential row -> browser/API DTO | Only allowlisted non-secret metadata may cross. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SC | Tampering | package-manager boundary | mitigate | No package operations; use approved DPAPI/store modules. |
| T-01-29 | Information Disclosure | add/status/validation responses | mitigate | Immediate protection, strict metadata DTOs and generated-canary suite. |
| T-01-30 | Tampering/DoS | failed in-place rotation | mitigate | Immutable versions, separate validation, atomic promote/generation and prior-key rollback. |
| T-01-31 | Elevation | stale client/version uses revoked key | mitigate | Expected version, generation invalidation, lease gates and idempotent transitions. |
| T-01-32 | Repudiation | lifecycle mutation without evidence | mitigate | State/generation/audit event in one serialized transaction. |
| T-01-33 | Information Disclosure | secret-derived masking/provider error | mitigate | Random display IDs, stable safe categories and no raw body/header/exception. |
</threat_model>
