## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| credential handle -> provider HTTP/audio transport | Plaintext crosses only after auth/control/generation validation and for one request. |
| lifecycle generation -> long-lived caches | Stale objects must not continue using revoked/draining credentials. |
| provider response -> API/audit/router | Remote content is untrusted and may echo sensitive data. |
