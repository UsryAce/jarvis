## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hidden operator input -> verifier | Unlock credential must never be printed or stored reversibly. |
| legacy env/config -> CredentialService | Real plaintext may exist only in the importing Python process memory during deliberate migration. |
| cutover -> restarted processes | Old environment/client objects may retain plaintext until stopped. |
