<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser memory/storage -> session authority | Browser code cannot read HttpOnly session and must not persist CSRF/unlock values. |
| unauthenticated root -> protected components | Merely rendering a component can start queries, streams, audio or disclose stale metadata. |
| ambiguous mutation -> retry | Timeout/expiry does not prove whether a command applied. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SC | Tampering | npm dependencies | mitigate | No npm install or registry block; reuse existing React/axios/lucide stack only. |
| T-01-44 | Information Disclosure | localStorage/DOM/URL | mitigate | HttpOnly cookie, memory-only CSRF/transient input and protected unmount/clear. |
| T-01-45 | Elevation | protected initialization before auth | mitigate | Root TrustBoundary waits for session plus control before mounting effects/routes. |
| T-01-46 | Tampering | blind retry after timeout/CSRF expiry | mitigate | Applied flag check, stale handling and GET reconciliation before repeat. |
| T-01-47 | Spoofing | wrong-scope treated as expiry | mitigate | Distinct authoritative error states and backend allowed_actions/scopes only. |
</threat_model>
