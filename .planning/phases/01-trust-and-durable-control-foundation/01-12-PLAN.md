<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend revision/version -> visual authority | UI must not invent, regress or prematurely complete state. |
| transient secret input -> frontend state/network | Secret must be cleared immediately and never retained for retry. |
| allowed_actions -> destructive control | Client roles/visual state cannot infer authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SC | Tampering | npm/registry boundary | mitigate | No dependency install or registry block; existing stack only. |
| T-01-48 | Tampering/Repudiation | optimistic/out-of-order UI state | mitigate | Greater-only revisions/versions, stale conflict refresh and ambiguous reconciliation. |
| T-01-49 | Information Disclosure | credential input/DTO/error | mitigate | Transient clear, metadata allowlist, safe notices and no generic dumps. |
| T-01-50 | Elevation | client-inferred destructive action | mitigate | Backend allowed_actions plus expected version/revision and re-auth where required. |
| T-01-51 | Repudiation | UI claims stop/revoke complete | mitigate | Accepted/transitional copy until newer authoritative terminal evidence. |
